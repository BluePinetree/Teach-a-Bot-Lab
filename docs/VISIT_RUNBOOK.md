## 1. 조마다 실행
```powershell
.venv\Scripts\python.exe -m teachabot.aloha_app --visit 1조 --visit-demos 3 --video data\videos\visit_1조.mp4
```
- 조 코드는 이름 없이 `1조`, `2조`… (개인정보 저장 안 함). 데이터는 `data/demos/s1/1조_*.npz`.
- 영상은 판 진행·공부·결과 화면만 녹화(대기 화면 제외).

## 2. 조별 진행 순서와 키
| 단계 | 화면 아래 표시 | 학생 | 진행자 키 | 예상 시간 |
|---|---|---|---|---|
| 연습 | "연습 (저장 안 함): □이동 □내리기 □집어 들기 □손목" | 한 명씩 자유롭게 움직여 보기(A로 시작, 시간 제한 없음). 4개 다 체크되면 "준비 완료" | 캡처/홈 = 다음 학생(체크리스트 초기화), **N** = 시범 시작 | 학생당 30~60초 (리허설에서 측정) |
| ① 시범 | ① 시범 강조, "성공 n/3판" | 한 명씩 조이콘 두 개로 큐브 2개 정리 (A로 시작) | 캡처/홈 = 다음 배치 | 판당 10~30초 + 교대 (리허설에서 측정) |
| ② AI 공부 | "AI가 공부하는 중… / 시험 보는 중…" | 막대가 생기는 것 보기 | 성공 시범 ≥1이면 **X** (또는 N) | 학습 ~15~25초 + 시험 40판 ~15~25초 |
| ③ AI 시연 | AI / 사람이 넘겨받음 표시, "AI 0.5배속" | AI가 멈추면 **자동 일시정지** + 그 손 상자 깜빡임 → 그 손의 스틱이나 버튼으로 넘겨받아 마무리 | A = 시작 / 일시정지 중 A = AI에게 계속 맡기기, 캡처/홈 = 다음 배치 | AI만 조종하는 동안 0.5배속(넘겨받으면 1배속), 판당 ≤40초(일시정지 중엔 시간 멈춤) |
| ④ 다시 공부 | 막대 한 줄 추가 | 막대가 오르는지 보기 | 넘겨받은 판 ≥1이면 **X** | ~30~50초 |
| ⑤ 결과 | 조 결과 + 참고 숫자(미리 잰 값) | — | ③에서 **N** | 1~2분 설명 |
| 끝 | | | **Esc** (요약이 `data/logs/aloha_s1_visit_*.json`, 단계별 시각 포함) | |

자동 시험(사람 대신 스크립트, 시험 전용, 창 없이 실행)으로 전체 사슬 연습→①→⑤가 오류 없이 도는 것은 확인함(공부 1회 ~40초, 시험 10판 기준; AI 멈춤 자동 일시정지 → 넘겨받기로 재개 확인). **사람이 하는 시간은 리허설에서 처음 잰다.**

### 리허설 피드백 반영 (2026-10-20)
- "개입을 안 했는데 그냥 끝났다"(실제로는 자동 시험 창이었음) → 실제 모드에도 있던 문제 해결: AI 멈춤 감지(목표가 1.5초 동안 1cm 미만 이동, 큐브가 상자 밖) 시 자동 일시정지, AI 판 0.5배속(`--ai-speed`), 연습 단계 추가(`--visit-no-practice`로 생략 가능).

## 3. 진행자 말 (예시, 숫자는 화면 그대로 읽기)
- 연습: "먼저 조이콘으로 로봇 팔을 움직여 봐요. 스틱은 이동, L/R을 누르고 있으면 내려가고, ZL/ZR은 집기, 조이콘을 기울이면 손목이 기울어요. 화면 아래 네모가 다 채워지면 준비 완료!"
- ① "이 로봇은 구글 딥마인드·스탠퍼드가 만든 ALOHA 2를 그대로 옮긴 시뮬레이션이에요. 아직 아무것도 몰라요. 여러분이 조이콘으로 시범을 보여 주세요."
- ② "지금 AI가 여러분 시범을 보고 공부해요. 공부가 끝나면 처음 보는 큐브 배치 40판으로 시험을 봐요." (막대 = 시험 결과, 꾸민 숫자 없음)
- ③ "이제 AI가 혼자 해요(천천히 보여 줄게요). AI가 멈추면 화면이 멈추고 그 손이 깜빡여요. 그 손의 스틱을 움직여서 고쳐 주세요. 고쳐 준 부분만 다시 공부해요."
- ④ "고쳐 준 걸로 다시 공부했어요. 막대가 올라갔나요?" (내려갈 수도 있음 → "시범이 적으면 결과가 들쭉날쭉해요. 그래서 연구에서는 몇백 판으로 재요"라고 정직하게)
- ⑤ "연구실에서 시범 10개 + 고쳐 주기 10번으로 가르친 AI는 이만큼, 시범 없이 혼자 300시간 넘게 연습한 강화학습은 이만큼이에요." (참고 숫자는 `config/visit_reference.json`, 출처 포함)

## 4. 리허설에서 잴 것
- [ ] 한 조 전체 시간(연습~⑤), 단계별 시간(요약 JSON `visit.steps`)
- [ ] 연습 체크리스트 4개가 학생당 몇 초에 다 채워지는지, 연습 후 첫 시범 성공률
- [ ] AI 멈춤 일시정지가 너무 자주/드물게 뜨는지(1.5초·1cm 기준), 0.5배속이 너무 느린지
- [ ] 학생 한 명 시범 시간과 성공률(처음 잡는 사람 기준)
- [ ] 시범 3개만으로 공부한 AI의 시험 결과(예상: 시범 3개 곡선값 성공 2%·큐브 0.25 — 16번 문서) → 학생들이 "나아짐"을 볼 수 있는지
- [ ] 강화학습을 끈 상태에서 공부+시험 시간
- [ ] TV 화면에서 글씨 크기·막대 가독성
- [ ] 조이콘 15분 절전 경고가 진행 중 뜨는지(연결 관리자)

## 5. 정할 것 (리허설 후 결정)
1. **학습 데이터 정책**
   - (가) 조별 백지 시작: 그 조의 시범·개입만 학습. 시범 3개면 AI가 대부분 실패(측정: 시범 3개 성공 2%·큐브 0.25)하지만 "우리가 가르친 만큼"이 그대로 보임.
   - (나) 연구실 기본 데이터 위에 더하기: `--visit-base s01 t01`. AI가 처음부터 37% 수준이라 시연은 안정적이지만 시범 3개를 더한 효과는 40판 시험 오차(±7%p 안팎)에 묻힐 수 있음.
   - (다) 그날 조끼리 누적: `--visit-base 1조 2조 …`. 뒤 조로 갈수록 AI가 좋아지는 이야기("선배 조가 가르친 AI").
2. 조별 시범 수(3? 5?)와 조당 시간
3. 시험 판 수(`--eval-episodes`, 기본 40 ≈ 오차 ±7%p, 20이면 더 빠르지만 더 들쭉날쭉)

## 6. 문제가 생기면
| 증상 | 대처 |
|---|---|
| 조이콘 "연결 안 됨" | 연결 관리자 창 확인 → 고착이면 안내대로 SYNC 한 번(50~60초). 급하면 키보드: `--input keyboard` (WASD/방향키, E/오른Shift 내리기, Q/오른Ctrl 집기, Space 시작) |
| 진행 중 연결 끊김 | 자동 일시정지 → 다시 연결되면 A |
| 공부 실패 표시 | 이전 AI로 계속됨. 성공한 시범이 없으면 공부할 수 없음 → 시범 한 판 더 |
| AI가 아무것도 못 함 | 정상일 수 있음(시범이 적음). ③에서 넘겨받기로 진행, ⑤에서 연구실 기준 숫자로 설명 |
| 창이 멈춘 것 같음 | 공부·시험 중(최대 1분 안팎). 화면 가운데 진행 표시 확인 |
